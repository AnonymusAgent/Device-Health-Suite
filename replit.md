# Veylo

The project documentation now lives in [README.md](README.md), with the baseline audit in [docs/AUDIT.md](docs/AUDIT.md) and implementation details in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Run `npm ci`, then `npm run web:preview` to build and serve the app on port 5000. For interactive web development, use `npm run dev`. For native development, use `npm start` with a compatible Expo Go client or development build.

No Replit-specific API domain, database, or billing key is required for the local app.
